El objetivo es definir una única fuente de verdad (Single Source of Truth) para el diseño visual, componentes, reglas de interfaz y gobernanza.

# Design Principles

Scientific Graph AI follows these principles:

- Consistency
- Predictability
- Accessibility
- Scientific Precision
- Workspace First
- Design Token Driven
- Component Reusability

---

# Source of Truth

The documents in this directory are the official UX/UI reference for Scientific Graph AI.

Any implementation must follow these specifications.

If implementation and documentation differ, the documentation takes precedence until officially updated.

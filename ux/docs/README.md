# Overview

This directory contains the official Design System for Scientific Graph AI.

The Design System defines the visual language, reusable components, design tokens, layout principles, accessibility standards, and governance rules used throughout the application.

These documents are considered the **Single Source of Truth (SSOT)** for all UI and UX decisions.

# Design Principles

Scientific Graph AI follows these core principles:

- Workspace First
- Scientific Precision
- Consistency
- Predictability
- Accessibility by Default
- Design Token Driven
- Component Reusability
- Performance-Oriented UI

---

# Single Source of Truth

The documents contained in this directory are the official UX/UI specification.

Whenever implementation differs from documentation, the documentation is considered authoritative until officially updated.

---

# Governance

Every new component or visual modification must:

- Follow the Design System
- Reuse existing design tokens
- Respect accessibility requirements
- Preserve visual consistency
- Avoid introducing undocumented patterns

---

# Versioning

This Design System follows semantic versioning.

Examples:

- v1.0
- v1.1
- v1.2
- v2.0

All significant changes must be recorded in `CHANGELOG.md`.

## 3. Relación con D65 / D66 / D67 / D68

| Serie | Relación con D69 |
|-------|------------------|
| **D65 Session Foundation** | Registry = SSOT runtime; Snapshot captura SessionState; no modifica Registry/Context |
| **D66 Session Persistence** | Independiente; SnapshotRecord ≠ PersistenceRecord; sin IndexedDB en snapshots/ |
| **D67 Session Restore** | Intacta; input sigue siendo PersistenceRecord[]; MissingSnapshot ≠ SessionSnapshot |
| **D68 Session Autosave** | Intacta; no llama `createSessionSnapshot` (AUTOSAVE reason reservado D70) |

```text
D65 Session  →  runtime SSOT (Registry)
D66 Persist  →  write path (Bridge → Adapter → IDB)
D67 Restore  →  read path (load → deserialize → register)
D68 Autosave →  mutation → policy → Bridge write
D69 Snapshot →  SessionState → immutable Snapshot → Map Store / Record
```

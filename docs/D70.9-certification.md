## 2. Objetivos certificados

1. Capa adicional sobre Session Snapshots (D69) sin modificar Freezes D65–D69.
2. RestorePoint encapsula `SessionSnapshot` completo (composición).
3. Factory: `createRestorePoint` → `createSessionSnapshot(RESTORE_POINT)` → wrap.
4. Registry Map SSOT · surface Freeze · **HR-rp-snapshot-identity**.
5. Ser/deser puros reutilizando D69 · sin IndexedDB / Adapter / Bridge.
6. Barrel aislado `@/components/session/restorePoints`.
7. Suite `validate:d70-gate` con cascada D65–D69.

---

## 3. Arquitectura certificada

```text
Session (D65)
  → SessionSnapshot (D69)
    → RestorePoint (D70)

createRestorePoint
  → createSessionSnapshot(..., SnapshotReason.RESTORE_POINT)
  → wrap RestorePoint
  → registry.create (Map SSOT)
  → (optional) serialize / deserialize
```

**Prohibido (verificado):** RestorePoint → SessionRegistry · RestorePoint → Provider.

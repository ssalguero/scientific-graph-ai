## 1. Resumen ejecutivo

**D69 — Session Snapshots Foundation** entrega la infraestructura desacoplada de **snapshots inmutables** de SessionState: Factory · Store (Map SSOT) · Serializer/Deserializer con schema version · barrel aislado · wiring privado en `SessionProvider`, sin UI, sin restore-point product, sin historial/versionado/backup/export avanzado (D70+).

Compatible con Freezes D65–D68 **sin refactor** de Registry, Persistence, Restore, Autosave ni Context públicos.

Documentación de certificación completa. Suite `validate:d69-gate` en verde. Proyecto listo para **D69.11 — CA Official** y **D69.12 — Release**.

---

## 2. Arquitectura final

```text
SessionRegistry (SSOT runtime)
        │  (caller extracts SessionState)
        ▼
SnapshotFactory  →  SessionSnapshot (immutable)
        │
        ▼
SnapshotStore (Map SSOT · in-memory)
        │
        ▼
Serializer / Deserializer  →  SessionSnapshotRecord (+ schemaVersion)
        ✗ no IndexedDB · no Registry mutation · no Restore rewrite

SessionProvider
        └── snapshotStoreRef (useRef · private · no Context / API)
```

**Session permanece la única fuente de verdad del runtime.** Snapshot solo captura estado.

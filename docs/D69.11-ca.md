## 2. Criterios de aceptación (CA-D69)

| ID | Criterio | Evidencia | Resultado |
|----|----------|-----------|-----------|
| **CA-D69-01** | Snapshot completamente inmutable (`readonly` SessionSnapshot) | `SessionSnapshotTypes.ts` · `validate:d69` readonly cases | **PASS** |
| **CA-D69-02** | SnapshotStore basado en `Map` como SSOT | `SessionSnapshotStore.ts` · API create/get/remove/clear/list/count | **PASS** |
| **CA-D69-03** | SnapshotFactory con responsabilidad única (SessionState → Snapshot) | `SessionSnapshotFactory.ts` · sin persist/register/restore | **PASS** |
| **CA-D69-04** | Serialización/deserialización puras e independientes de IndexedDB | Serializer · Deserializer · sin I/O | **PASS** |
| **CA-D69-05** | Gate de schema version (`SNAPSHOT_SCHEMA_VERSION`) | Record embed · deserialize reject unsupported | **PASS** |
| **CA-D69-06** | Package `snapshots/` aislado (barrel limpio · sin imports cruzados) | `snapshots/index.ts` · import isolation · no re-export desde `session/index` | **PASS** |
| **CA-D69-07** | SessionProvider incorpora SnapshotStore de forma privada mediante `useRef` | `SessionProvider.tsx` · `snapshotStoreRef` | **PASS** |
| **CA-D69-08** | Sin cambios / exposición en APIs públicas de Context (D65–D68) | SessionContext / SessionAPI sin SnapshotStore · mutators intactos | **PASS** |
| **CA-D69-09** | `validate:d69-gate` en verde | Umbrella d65→d68 gates + `validate:d69` (28/28) | **PASS** |

**CA-D69 = PASS (9/9).**
